Pré-prompts du pipeline d'analyse

Le pipeline routed enchaîne : (1) le routeur classe chaque cotation (classe d'actif + famille), (2) une cascade déterministe choisit le pré-prompt de domaine le plus précis ({famille}-{classe} → {classe} → default), (3) l'extraction est faite avec ce pré-prompt + les règles transverses (_common). Les lignes protégé (router, _common, default) sont modifiables mais non supprimables.
